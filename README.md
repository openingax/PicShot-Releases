# PicShot for macOS

PicShot 是一款 macOS 14 及以上版本的状态栏截图工具，支持区域截图、标注、贴图和滚动长图。

## 下载与更新

正式安装包发布在 [GitHub Releases](https://github.com/openingax/PicShot-Releases/releases)。下载对应版本的 PicShot ZIP，解压后将 PicShot 放入「应用程序」文件夹。

从集成 Sparkle 的版本开始，可在 PicShot 状态栏菜单中选择「检查更新…」，查看新版、下载安装并重新打开应用。每个正式 Release 随附已签名的更新包和更新清单。

第一次截图需要 macOS 的录屏权限；自动滚动还需要辅助功能权限。
